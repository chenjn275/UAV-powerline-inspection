# 软件功能说明书草案

## 1. 软件定位

软件用于已知三维输电线路模型下的四旋翼巡检任务规划与安全状态管理。首版在静态障碍、低速和仿真条件下运行，不替代带电线路作业审批、绝缘距离核定或飞控安全认证。

## 2. 功能模块

### 2.1 线路模型

加载带版本号的中心线，以弧长查询位置和切向，使用平行运输标架生成稳定截面法向与副法向。直线段不使用退化的 Frenet 法向。

### 2.2 参考扫描

按用户给定的区段、半径、角度振幅、周期和沿线速度生成时间参数化圆弧参考。参考半径是期望约束，不能替代整段净空检查。

### 2.3 候选与安全

在有限半径/角度集合上生成候选，检查完整采样轨迹到整条导线和障碍物的净空，并记录拒绝原因、最小距离和评分。

### 2.4 覆盖与恢复

把任务划分为弧长与观察角单元。只有满足距离、可见、无遮挡和清晰度门槛的观测才能完成单元。中断后从未完成单元选择安全重接入位置。

### 2.5 故障与状态

输入过期、链路中断和多故障分别进入健康状态；任务状态经过等待观测、扫描、制动、重接和完成门槛。系统不把定位丢失自动解释为可靠悬停或返航。

## 3. 输出

- ROS 2 `inspection/status`：候选和任务阶段；
- ROS 2 `inspection/reference_path`：供后续规划适配器检查的参考路径；
- ROS 2 `inspection/coverage`：有效观测覆盖状态；
- JSON 验证报告：候选、安全、覆盖和重接入证据。
