# 软件著作权 V1.0 材料草案

拟申请名称：**输电线路三维巡检任务规划与安全控制软件 V1.0**

本目录是研发材料草案，不是已经提交或受理的登记申请。申请主体、权属、发明人/开发者、源程序页数和官方格式必须按提交时的中国版权保护中心要求核定。

## 原创范围

本项目原创代码范围目前包括：

- `inspection_core`：已知导线模型、平行运输标架、恒半径扫描、候选半径/角度筛选、净空检查、覆盖网格、重接入、健康判定、任务状态机和坐标适配参考；
- `inspection_manager`：ROS 2 参数加载、候选结果发布、参考路径发布、覆盖等待状态发布和任务状态边界；
- 配置、验证脚本、测试和项目文档中由本项目编写的部分。

SUPER、ROS 2、Eigen、PCL、OpenCV、FAST-LIO2、Livox 驱动、RealSense ROS、PX4 和其他依赖均保留其来源与许可证，不作为本项目全部原创代码申报。

## 建议材料清单

1. 软件功能说明书：任务创建、导线模型、候选轨迹、安全拒绝、覆盖记录、故障状态和报告导出。
2. 用户操作说明：工作区构建、环境加载、基线场景运行、ROS 话题和验证报告位置。
3. 源程序鉴别材料：只选项目原创源文件，保留版本号、日期和文件清单，不复制第三方源码。
4. 权属材料：开发人员、单位/委托关系、贡献记录和版本历史。
5. 许可证清单：引用 [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md)。
6. 验证证据：测试输出、`artifacts/baseline_scenario.json`、构建日志和版本锁定文件。
