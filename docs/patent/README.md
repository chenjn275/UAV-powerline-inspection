# 发明候选材料草案

暂定名称：**一种基于动态安全半径和轨迹重接入的四旋翼输电线路巡检方法及系统**。

本目录只记录研发交底和检索准备，不代表已经完成三库检索、具备新颖性或保证授权。申请前必须取得可核验的专利/非专利文献全文，并逐项完成特征对照。

候选核心机制：在已知导线几何、机体包络、地图和误差边界下，枚举半径/角度候选；对完整轨迹与备用轨迹做净空验证；执行安全候选；轨迹受阻时冻结有效覆盖单元，选择安全可达且能补齐遗漏的重接入单元，完成有效观测后再继续任务。

实施例工具可以使用 SUPER、ROS 2、FAST-LIO2、YOLO 和 PX4，但这些第三方工具的公开机制不自动构成本项目的原创特征。
